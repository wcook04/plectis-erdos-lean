file, an axiom audit, a Comparator configuration and a `formalization.yaml` with
the full mathematical description, sources and limits. The proof of each is in
[`Solutions/`](../Solutions/). None of them solves an original open problem, and
the [README](../README.md#the-eight-problems) gives the state of each problem.
