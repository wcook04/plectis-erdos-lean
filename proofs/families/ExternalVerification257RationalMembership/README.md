# Rational greedy-skip membership

A nonnegative rational belongs to the base-two Mersenne achievement set
exactly when its canonical greedy orbit omits infinitely many positive
exponents. Infinite skipped support is equivalent to a cofinal supply of
skipped greedy branches. Represented rationals necessarily have infinite
skipped support.

The Challenge imports only Mathlib and restates the achievement set, greedy
remainder, selected support, and skipped support. The Solution transports the
four source endpoints from `Erdos257PeriodNoncollapse.GreedyAchievementSet`.
These equivalences do not construct an infinite skipped support for any
particular rational, including `1/2` and `1/21`, and do not settle Erdős #257.
