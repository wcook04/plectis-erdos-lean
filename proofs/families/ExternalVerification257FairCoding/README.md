# Fair coding of the Mersenne achievement set

Fair infinite product measure on `{0,1}^ℕ` is pushed forward by the
positive-index Mersenne coding map onto Lebesgue measure restricted to the
achievement set. The same map is measure-preserving for that pair of
measures. The preimage of the rationals under the coding map is a null set
for fair digit measure.

The Challenge imports only Mathlib and restates the coding map, the
achievement set, and the fair product measure. The Solution transports the
three source endpoints from `ErdosProblems.Erdos257.PaperGeometryCompletion`.
These identities do not prove irrationality of every infinite Mersenne
subseries and do not settle Erdős #257.
